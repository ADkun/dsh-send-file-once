# 一次性文件快传（send-file-once）

## 核心目标与审美宣言
把任意文件或一段机密文本，用一条命令变成「阅后即焚」的一次性链接：端到端加密、链接即钥匙、到期或用完次数即自动作废。取舍只有一个——**绝不把明文或链接当成可公开的信息**；宁可少发一条链接，也不多泄露一次内容。产出必须干净：一条链接 + 三个关键参数（有效期 / 可用次数 / 是否有口令）+ 一句「链接即钥匙」的提醒，其余一概不留。

## 触发与决策路由
启动时机：用户说「发个文件 / 传个东西给对方 / 生成下载链接 / 阅后即焚 / 一次性 / 限次下载 / 给个链接让他取」，或要把密钥、口令、票据、备份码、恢复码等敏感文本安全递出。

按情形路由：
- 传的是**文件** → 用 `send --file <路径>`。
- 传的是**一段机密文本**（密码 / Token / 密钥 / 恢复码）→ 用 `send --text <内容>`（文本接口不支持口令；极敏可先加密成文件再发）。
- 用户**没指定**有效期 / 次数 → 用默认（1 天 / 1 次），交付时说明「已按最严默认，需要更宽松再告诉我」。
- 用户要**多端 / 多人取** → 调高 `--views`（1–10），并提示每多一次就多一份泄露面。
- 内容**高度敏感** → 加 `--passphrase`（口令另走安全渠道告知，绝不能和链接同一通道发）。
- **自建 / 私有实例** → 加 `--host <origin>`（见 references/cli-reference.md）。

## 核心工作流

### Phase 0 自检
- 执行指令：运行 `bash scripts/otf.sh doctor`。
- 退出条件：打印出 node 版本且显示 `1time : 可用`；若缺失，先 `npm install -g @1time/cli`（需 Node ≥ 20）再继续。

### Phase 1 定参
- 执行指令：按上面的决策路由确定「文件/文本、`--expires`、`--views`、是否 `--passphrase`」四个取值。
- 退出条件：四项都有明确值（未指定即取默认 1d / 1 / 无口令），不再靠猜。

### Phase 2 发送
- 执行指令：`bash scripts/otf.sh send --file <路径> [--expires 2d] [--views 3] [--passphrase <口令>]`（或 `--text <内容>`）必须作为**后台任务**执行：脚本全程非交互，大文件上传可达数分钟；任务结束后读回输出取链接（要机读就加 `--json`）。
- 退出条件：任务输出出现一条 `https://1time.io/f/#...`（文本为 `/v/#...`）链接，且退出码为 0。非 0 时按退出码读 stderr 定位（2 校验 / 3 上传失败 / 4 依赖缺失）。

### Phase 3 交付
- 执行指令：把 **链接**、**有效期**、**可用次数**、**是否有口令** 四项压成一句人话发给用户，并附「链接 # 之后即解密钥匙，只能发给目标接收人；到期或下载次数用尽自动作废」。
- 退出条件：用户拿到链接与三个参数；若设了口令，明确告知「口令需另走安全渠道（当面 / 加密 IM）转告，切勿与链接同发」。
- 可选自证：只有 `--views ≥ 2` 且用户同意时才读回校验——`bash scripts/otf.sh read <链接> --out <新路径>`（大文件同样走后台任务）会消耗一次次数；`--views 1` 时读回等于把链接用废，不做。`--out` 指向已存在的文件会被 1time 直接拒绝，务必换新路径。

## 执行约束与红线
- 红线：链接的 `#` 之后就是解密钥匙，**链接本身即秘密**。绝不把链接贴进公开群、工单、日志、截图或对话记录，只发给目标接收人。
- 红线：`--text` / `--passphrase` 的取值在调用侧就是 argv——会留在对话记录、shell 历史与进程列表里；脚本只在最后一跳转成 stdin / 环境变量，护不到调用侧。故二者只用于「留痕可接受」的内容；私钥、恢复码、长期凭证一律先加密成文件再发，且永不把明文复述进正文、日志或截图。
- 红线：口令与链接必须走**两条不同通道**；两者同发等于没加密。
- 红线：单文件超过 250MiB（脚本默认上限，`--max-mb` 可调；1time 服务端不校验大小、会把整文件读进内存）即拒绝，不得为省事擅自放大——分卷、压缩或改用其他方案，并如实告知。
- 约束：链接只存在于后台任务的输出里——没读到就不交付（不得凭印象补一条），读到当轮交付，别留到下一轮。
- 约束：`--views` 越大、`--expires` 越长，泄露面越大；除非用户明确要求，一律用默认（1 次 / 1 天）。
- 约束：公共实例有速率限制，短时间批量失败先 `doctor` 排查，不要连刷。
- 约束：只操作自己的文件与已授权内容；不读取、不解密、不转发他人未授权的一次性链接。
