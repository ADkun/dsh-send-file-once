# 示例：把一份备份码一次性发给同事

> 仅供模仿结构与话术，严禁照搬具体内容。

用户：帮我把桌面的 backup-codes.txt 发给小李，限他下载一次，明天前取。

执行：
1. doctor 自检 → 1time 可用。
2. 判断：文件；次数 = 1（用户明确「一次」）；有效期 = 1d（「明天前」）；敏感 = 是 → 建议加口令。
3. 发送（后台任务；口令另发）：
   bash scripts/otf.sh send --file "C:/Users/me/Desktop/backup-codes.txt" --expires 1d --views 1 --passphrase <口令>
   （口令会留在本地 argv / shell 历史里，只用于留痕可接受的场景）
4. 任务结束后读回任务输出，取其中的链接。
5. 交付链接、有效期、次数、口令情况。

助手交付话术：
  已生成一次性链接（阅后即焚）：
  链接：https://1time.io/f/#xxxx
  有效期 1 天 · 可下载 1 次 · 已加口令
  提示：链接 # 之后即解密钥匙，只能发给小李本人；口令请通过电话或当面另告，切勿与链接同发。到期或下载一次后自动作废。
